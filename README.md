# 废话过滤器

## 项目作用

“废话过滤器”是一个用来判断一句话**值不值得发出去**的小工具。

它不是帮你改文案，也不是替你写回复。

它做的事情很简单：

在你发消息、朋友圈、评论之前，先把那句话贴进去。
然后它会像一面镜子一样，给你一个外部确认。

很多时候，你心里其实已经知道这句话该不该发。
只是需要一个系统替你再看一眼。

## 核心功能

输入一段你准备发出去的文字后，系统会返回 3 个结果：

- **有用吗**
  - 1 到 10 分
  - 分数越高，说明这句话越像沟通、信息、请求或表达

- **会惹事吗**
  - 1 到 10 分
  - 分数越高，说明这句话越容易引发误解、冲突、冒犯或公开风险

- **明天看会后悔吗**
  - `是` / `否`
  - 用来判断这句话是否更像冲动表达，而不是清晰表达

此外，系统还会给出一句简短的“镜子式判断”，例如：

- **可以发。你大概率不是在发泄，而是在表达。**
- **先别急着发。你心里其实已经知道，这句话更像情绪，不像信息。**

## 当前技术方案

这个项目使用：

- **前端**：原生 HTML + CSS + JavaScript
- **后端**：Node.js + Express
- **大模型**：DeepSeek API

当前后端分析逻辑是：

- **优先调用 DeepSeek**
- **如果没有配置 API Key，或调用失败，则自动回退到本地规则分析**

这样做的好处是：

- **有模型时**，判断更灵活、更像真人理解
- **没模型时**，应用依然可用，不会直接报废

## 适合的使用场景

你可以在这些场景里使用它：

- **发消息前**
  - 比如准备给朋友、同事、前任、领导发一句话时

- **发朋友圈前**
  - 比如准备发一条带情绪、暗示、阴阳怪气的内容时

- **发评论前**
  - 比如准备在评论区回一句有点冲的内容时

- **情绪上头时**
  - 当你不确定自己是在表达，还是在发泄时

## DeepSeek 配置方式

项目根目录下需要有一个 `.env` 文件。

示例内容如下：

```env
DEEPSEEK_API_KEY=你的_deepseek_api_key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
```

### 字段说明

- **DEEPSEEK_API_KEY**
  - 你的 DeepSeek API Key

- **DEEPSEEK_BASE_URL**
  - DeepSeek 接口地址
  - 默认值是：`https://api.deepseek.com`

- **DEEPSEEK_MODEL**
  - 使用的模型名称
  - 当前默认值是：`deepseek-chat`

## 使用方法

### 1. 打开页面

启动项目后，进入浏览器页面。

### 2. 粘贴一句你准备发的话

把消息、朋友圈文案或评论内容粘贴到输入框中。

### 3. 点击“照一下镜子”

系统会返回：

- **有用吗** 分数
- **会惹事吗** 分数
- **明天看会后悔吗**
- **一句镜子式判断**

### 4. 查看结果来源

页面会提示本次分析来自哪里：

- **本次结果由 DeepSeek 生成。**
- **未检测到可用 DeepSeek 配置，当前为本地规则结果。**

## 产品定位

这个工具的核心创意不是“帮你改文案”。

而是：

**帮你照镜子。**

它不替你表达，也不替你做决定。
它只是把你本来就隐约知道的判断，更明确地摆到你面前。

所以它更像：

- **一个发出去之前的暂停键**
- **一个帮你确认情绪状态的外部视角**
- **一个低成本、低打扰的表达检查器**

---

## 注意事项

- **不要把 API Key 写到前端代码里**
  - Key 应该只放在服务端 `.env` 中

- **建议使用 Node.js 18 或更高版本**
  - 当前后端使用了原生 `fetch`

- **本地规则只是兜底**
  - 如果你希望判断结果更自然，建议配置 DeepSeek

## 总结

“废话过滤器”不是一个替你优化表达的写作工具。

它更像一个在你准备按下发送键之前，帮你确认一句话值不值得说的小镜子。

如果一句话本来就值得发，它会帮你更安心。
如果一句话只是情绪上头，它会提醒你慢一点。
